## What's New

We're excited to announce the latest Corelynk platform release, packed with features requested by our enterprise customers.

## Dashboard Enhancements

### Customisable KPI Widgets

Users can now drag-and-drop KPI cards to create personalised dashboard layouts. Save multiple views for different stakeholder groups.

### Enhanced Trend Visualisations

- Multi-series comparison charts with overlay capabilities
- Anomaly detection highlighting on trend lines
- Export to PNG, CSV, and PDF formats

### Improved Data Table

- Column-level filtering and sorting
- Bulk export with custom date ranges
- Inline status updates for account management

## API v2

Our redesigned REST API offers:

- **GraphQL endpoint** for flexible data queries
- **Webhook subscriptions** for real-time alert delivery
- **Rate limiting** with transparent usage dashboards
- **OAuth 2.0** authentication with scoped permissions

Full API documentation is available at `docs.corelynk.co.uk/api/v2`.

## Migration Notes

API v1 remains supported until December 2025. We recommend migrating to v2 to access new endpoints and improved performance. Contact your account manager for migration support.
